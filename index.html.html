Pratinjau Koneksi Link Soal

Pastikan soal tampil di dalam bingkai terkunci sebelum membagikan tautan ke siswa.

Tempel link soal yang mengizinkan penyematan bingkai (Canva Desain Embed, Google Form, Google Drive, Wordwall, Quizizz) di kolom sebelah kiri untuk memeriksa koneksinya di sini.

Panduan Tautan Soal Eksternal:

  • Canva: Mendukung tautan situs web Canva (*.my.canva.site) maupun tautan dari editor desain (canva.com/design/.../view atau menu Bagikan → Lainnya → Sematkan).
  • Google Form: Gunakan tautan lengkap docs.google.com/forms/d/e/.../viewform (tautan pendek forms.gle diblokir oleh kebijakan bingkai Google).
  • Google Drive / PDF / Docs / Slides: Set akses file menjadi Siapa saja yang memiliki link agar pratinjau tampil di dalam bingkai.
